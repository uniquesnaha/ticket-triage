# Project 1 — Support-Ticket Triage with Calibrated Structured Generation

Build a Python program that reads support tickets from the supplied CSV and assigns each ticket a structured triage result: `category`, `priority`, `sentiment`, `customer_impact`, `needs_human_review`, and a concise `rationale`. Use an LLM through an API or compatible local model. You must define and enforce a structured output schema rather than relying on free-form text. Preprocess noisy ticket text, including duplicated fragments, inconsistent capitalization, and irrelevant signatures. The program must validate model responses, retry malformed responses, and apply deterministic safeguards when model output conflicts with explicit evidence in the ticket. Produce one JSON object per input row.

The evaluator will inspect both implementation quality and behavioral robustness. Your solution should distinguish between model-derived judgments and deterministic rules and should avoid leaking unsupported claims into the rationale. Include reasonable handling for API failures and missing fields. You may use standard Python libraries plus one GenAI framework or SDK of your choice. The solution must work with an environment variable containing the model/API credentials and must not hard-code credentials.
